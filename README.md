## 🚀 Sobre o Projeto
O **TaskTracker** é uma aplicação CLI (Interface de Linha de Comando) desenvolvida em Python 3 para auxílio no gerenciamento e acompanhamento de tarefas diárias. Este projeto faz parte do desafio cumulativo do Bootcamp II.

## 💻 Como Executar o Projeto

1. Certifique-se de ter o Python 3 instalado no computador.
2. Navegue até a pasta do projeto no terminal:
   ```bash
   cd tasktracker-projeto
   ```
3. Execute o código principal em Python:
   ```bash
   python src/main.py
   ```
